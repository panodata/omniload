# Parquet

`omniload` reads [Apache Parquet] files. Apache Parquet ([Wikipedia])
is an open source, column-oriented data file format designed for
efficient data storage and retrieval.
It provides high performance compression and encoding schemes
to handle complex data in bulk and is supported in many programming
languages and analytics tools.

Parquet is supported for read and write operations.


[Apache Parquet]: https://parquet.apache.org/
[Wikipedia]: https://en.wikipedia.org/wiki/Apache_Parquet
